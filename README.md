## Selected Projects

### PulseForge
Pre-merge CI infrastructure that replays sanitized production traffic against candidate branches and blocks regressions before deployment.

- Reduced gate runtime from 14 minutes to 3 minutes.
- Reduced false blocks from 31% to 1.4% across 400+ runs.
- Detected 94% of seeded regressions on a 2,000-request budget, compared with 61% for random sampling.
- Built around AWS, FastAPI, OpenTelemetry, Terraform, and GitHub Actions.

### Faxtract
Agentic document-processing pipeline that turns degraded faxed medical referrals into validated, insurance-verified imaging orders.

- Achieved 95.7% field accuracy at approximately $0.015 per order.
- Reduced processing time from approximately 20 minutes to 20 seconds.
- Uses Python, TypeScript, RAG, pgvector, X12, and HL7 v2.5.1.

[View on GitHub](https://github.com/DhruvDS2/faxtract)

### FindingNemo
A model-routing system designed to reduce inference costs by sending queries to specialized 8B models and falling back to a 253B generalist when needed.

- Uses FAISS for request clustering.
- Fine-tuned specialists with 4-bit QLoRA.
- Reduced training time by 45%.

[View on GitHub](https://github.com/Tan-Agg/FindingNemo)

### CometDash
Finalist project in the Verizon Smart Campus Competition. Designed a real-time transit tracking system using GPS, occupancy sensors, 5G edge computing, and gradient-boosted arrival models to improve bus arrival predictions.
